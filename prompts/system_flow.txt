--------------------------------------------------
HOME SCREEN STRUCTURE
--------------------------------------------------

Home screen layout:
- Left: vertical side menu
- Center/top: headings (NOT focusable)
- Below headings: horizontal tabs
- Below tabs: content tiles

Headings (not focusable):
- "Explore your favourite content quickly and easily"
- "Everything you want is here - enjoy a range of apps and content with Smart Hub."

Tabs (left to right):
1. For You
2. Live
3. Apps

Focused tab appears with white rounded background.

--------------------------------------------------
TAB CONTENT
--------------------------------------------------

For You:
- Sections: Recent, TV Plus Recommendation

Live:
- Sections: On Now, Live Sports

Apps:
- Sections: Editor's Choice, Downloaded App

Tiles are navigated horizontally.
KEY_UP returns focus toward tabs.

--------------------------------------------------
SIDE MENU (VERTICAL)
--------------------------------------------------

Side menu items (top to bottom):
1. User Profile
2. Search
3. Home
4. Connected Devices
5. Settings
6. Privacy Choices

Behavior:
- Side menu opens when navigating LEFT from Home screen.
- When side menu opens, focus ALWAYS starts on "Home".
- KEY_UP / KEY_DOWN move within side menu.
- KEY_RIGHT exits side menu.
- KEY_ENTER selects item.

--------------------------------------------------
SEARCH SCREEN
--------------------------------------------------

When Search is opened (KEY_ENTER on Search icon):

- The Search screen is displayed.
- Focus INITIALLY lands on "Recently Viewed" content tiles.
- The Search input field (search bar) is ABOVE Recently Viewed.

Navigation rules on Search screen:
- KEY_UP moves focus from Recently Viewed → Search input field.
- KEY_ENTER on Search input field opens the virtual keyboard.
- KEY_DOWN moves back to Recently Viewed tiles.

--------------------------------------------------
SETTINGS (DEVELOP MODE) SCREEN
--------------------------------------------------

Screen title:
- "Settings (DEVELOP MODE)" (top-left, NOT focusable)

Top-right info area (NOT focusable):
- Storage usage indicator
  - "Used: <value>GB"
  - "Available: <value>GB (<percentage>)"
- Auto update toggle
  - Label: "Auto update : ON" or "Auto update : OFF"
  - Toggle state is visually indicated
  - Toggle is NOT focusable from this screen

--------------------------------------------------
SETTINGS SCREEN CONTENT
--------------------------------------------------

Main content:
- A horizontal row of application tiles

Visible app tiles may include (left to right):
- Sony LIV
- Gallery
- Spotify
- Internet
- Bixby
- YouTube

Behavior:
- Tiles are navigated using KEY_LEFT and KEY_RIGHT
- Exactly ONE app tile is focused at any time
- Focused tile appears visually highlighted

--------------------------------------------------
APP TILE CONTEXT MENU
--------------------------------------------------

When an app tile is focused:
- A context menu appears near the focused tile

Context menu items (top to bottom):
1. Add to Home
2. Delete
3. Lock

Behavior:
- Context menu items are vertically navigable
- KEY_UP / KEY_DOWN move within context menu
- KEY_ENTER selects the focused context menu action
- KEY_LEFT or KEY_RIGHT returns focus to app tiles

--------------------------------------------------
NAVIGATION RULES
--------------------------------------------------

- KEY_LEFT / KEY_RIGHT:
  - Move focus between app tiles
- KEY_UP:
  - No effect unless context menu is open
- KEY_DOWN:
  - No effect unless context menu is open
- KEY_ENTER:
  - On app tile → opens context menu
  - On context menu item → executes action
- KEY_HOME:
  - Returns to Home screen
